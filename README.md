# Savings story prototypes

Motion and static prototypes for the Modern Health "where most health care savings come from" module, in the same static setup as the home intro prototypes (plain HTML/CSS/JS, colorway tokens, GitHub Pages).

- `scroll/` – pinned scroll story (Day 1 to $2.39) with the iceberg closer
- `spotlight/` – adaptive care vs therapy-first toggle
- `staircase/` – static cost staircase

Add `?c=navy|navy-solid|neutral|sky` to pick a colorway, and `?p=0..1` on the scroll page to freeze the sequence. Prototype copy, not yet Legal-reviewed.
